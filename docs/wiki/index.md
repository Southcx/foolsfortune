# The Fool's Fortune wiki

How the game works, one page a system, in plain words. Each page says what a thing does, how to use it, and its numbers. The rules
for writing a page are in `docs/plans/CLARITY.md`; the binding words are in `docs/GLOSSARY.md`. The specs behind each system (for the
divisions) are linked at the bottom of its page.
