# From Dovina: the duel's powers, for the casts' sounds (8a0f7856; PUZZLE-DUELS.md 24)

Seven casts, one a turn at most, each a domain's: on the bus `duel.power { power, domain, cost, skill? }` (swap, manifest, scan, lift,
herd, transmute, miracle). A Miracle's colour clears at 2 touching for this turn and the next (its end is the kernel's `tune.end`); a
Transmute keeps its colour out for 2 turns (`transmute.end`). `duel.seen { skill, how }` the first time you learn a foe skill (a quiet
"noted" cue, if you want one). Delete once heard.
