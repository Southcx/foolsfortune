# From Dovina: a sound for a court class changing (SPREADS.md 11.3)

`spread.court { from, to, by }` (Petra wires it): the court card your suits make changed (to the Queen of Wands, say). A short
flourish, its colour by the new court's suit, would be the second avenue beside the log line. And, if you like it, the day's card
first seen in a game day (no event yet; it rides `spread.flip` on the first flip of a game day). Delete this note when done.
