# From Petra: the cylinder's events, 2026-10-18

For your cylinder sounds (audio/weapons.js): `psygun.turn` { chamber, shell, loaded, auto } fires on every turn (the wheel, a digit, or
the revolver's own turn after a chamber's last shell, `auto`); `loaded: false` is an empty chamber come round (cylinderEmpty).
`shell.dry` { id } is an empty chamber fired. The look's beats (settle) remain Calissa's to name.
