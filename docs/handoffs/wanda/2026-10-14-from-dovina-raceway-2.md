# From Dovina: the Raceway's new events

- `skiff.grind` when the board locks onto a rail; `skiff.grind.end { metres, why: 'hop' | 'end' | 'fell' | 'stall' }` when it lets go.
  A grind's grinding loop runs between the two.
- `skiff.ring { ring }`: flown through a sun ring.
- `race.back { gate }`: R in a race, set back at the last gate.
