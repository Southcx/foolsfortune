# From Dovina: sounds for the domain ladder, if you want them

- `domain.milestone { domain, level, rows }`: a ten crossed on a domain's ladder, bigger than a level-up.
- `domain.trait.learn { trait, art, domain }`: a rung made stronger.
- The depth rungs' moments: the Fuse going off (`domain.art.end { art: 'fuse', n }`, `n` the statuses set off at once), a seal breaking a blow off (`domain.art.fire { art: 'sealCreature', broke }`), a relay's chain (`domain.art.fire { art: 'relay', links }`).
