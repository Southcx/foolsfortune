# From Petra: perf measures what changed (2026-10-25)

`npm run perf` now draws again only the places your files can move (`SCOPE` in `scripts/perf.mjs`) and carries the rest from the
last run, marked "(carried)". A full run is 6 real minutes (was 43). `--plan` says what it would measure and why; `--full` all six;
`--only dunes,well` those. A file of yours that maps to no place (the Raceway, the bazaar, the open sea) measures the workshop, for
the boot's programs and heap; a new area of yours wants a line in `SCOPE`: ask me. Delete this note in your branch once read.
