## 3. The cloud save

- **The offer** (a later cloud copy, or the loser copy kept in the Codex), with the device's label when known:
  **"Your save from your phone, 3 real hours ago, played longer than this one. LOAD"**; unknown device: "from another device". Under an
  hour: "N real minutes ago"; under a minute: "just now". In the Codex while it is kept: **"Your other save, from your computer, 2 real
  hours ago. Kept until the next game day. LOAD"**
- **LOAD's confirm** (it replaces a running save, so one more press): **"Load it? The save you are playing now is kept here in its place."**
  This keeps the law that a real hour of play is never lost silently.
- **When the longer one wins at boot**, the log once: **"Your save from your phone was played longer, so it is the one loaded. The other is
  kept in the Codex until the next game day."**
- **Kept on this device only**, the log once: **"Your save is kept on this device only."** Signed out, add the way out: "Sign in to keep it
  on every device." (Only if signing in is something the page can offer; otherwise the first sentence alone.)
- **The devices' labels:** **"your computer"**, **"your phone"**, **"your tablet"**, and **"another device"** when the user agent can't
  say. Not "your desktop": the user agent can't tell a laptop from a desktop, and a laptop owner reads "desktop" as wrong. If the owner
  wants "desktop" anyway, it is a one-word swap.
- **A glossary entry** is owed when it is built: "the cloud save" (plain, the genre's word), Petra's code name. *Not:* the Box's storage,
  the export code.
