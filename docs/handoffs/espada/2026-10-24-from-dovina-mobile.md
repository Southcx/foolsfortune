# From Dovina: mobile play, the words (docs/plans/MOBILE.md)

The owner wants the whole game playable on a phone. Words you will be asked for, plain until the owner rules (MOBILE.md 4, 8):
the cluster's button labels where a glyph will not do (HOP, FLARE, BRAKE, BOOST, NOSE, TAIL, USE (it names its thing: "Race board"),
FIRE, GUARD, SPECIAL, BACK, RESTART, RETIRE), the top bar's window names, the help pages for touch (they say "Needs a keyboard and mouse"
today, and teach keys), and the glossary's new plain names (touch play, an input action, an axis, the last device, the move zone, the look
zone, the cluster, the top bar). The help pages also lag the code (the Veritome page still says "bank"; the skiff page omits the carve,
grabs and the shoulder: `docs/plans/research/MOBILE-AUDIT-INPUT.md` notes).
